# Day 41 - HTML Basics 🌐

The start of the **Web Foundations** section — four short exercises covering the fundamentals of HTML: heading hierarchy, paragraphs, void (self-closing) elements, and basic page structure.

---

## 1️⃣ Heading Elements

Practices HTML's heading hierarchy (`<h1>` through `<h4>`), structuring a book's table of contents — one `<h1>` title, `<h2>` chapters, and nested `<h3>`/`<h4>` sections and sub-sections.

**Concepts:** Semantic heading levels (`h1`–`h6`), document outline/hierarchy.

---

## 2️⃣ Paragraph Elements

Three `<p>` elements containing block-style body text, practicing how the browser renders paragraph spacing and wrapping.

**Concepts:** The `<p>` tag, block-level text flow.

---

## 3️⃣ Void Elements

A short biography page (William Blake) using **void elements** — `<br />` for line breaks within an address block, and `<hr />` as a horizontal divider between sections.

**Concepts:** Void/self-closing elements (`<br>`, `<hr>`), combining them with regular block elements like `<h1>` and `<p>`.

---

## 4️⃣ Movie Ranking

A simple personal top-3 movies list combining everything from the earlier exercises — headings for structure, an `<hr>` divider, and paragraphs describing each movie.

**Concepts:** Combining headings, paragraphs, and void elements into a small real page layout.

## 🧠 Concepts Practiced (Overall)

- Heading hierarchy and document structure (`h1`–`h4`)
- Paragraph text blocks (`<p>`)
- Void elements (`<br />`, `<hr />`)
- Basic semantic page composition

## 🚀 Run It

Open any `index.html` file directly in a browser — no server needed for these static pages.
