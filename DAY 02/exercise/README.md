# Day 02 — 📝 Exercises

> Part of my [100 Days of Python](../../) journey — Angela Yu's Python Pro Bootcamp

 Exercises completed before the Day 02 project (Tip Calculator). These cover Python's data types, type checking and conversion, mathematical operators, order of operations, rounding, and f-strings.

## 📂 Exercises

### 1️⃣ Data Types
Introduction to Python's four primitive data types — strings, integers, floats, and booleans — through simple `print()` examples of each.

**Concepts:** Strings, integers, floats, booleans

### 2️⃣ Type Checking & Type Conversion
Using `type()` to check the data type of a value, converting between types with `int()`, `str()`, `float()`, and `bool()`, and fixing a broken line of code by first converting an integer to a string before concatenating it with another string.

**Concepts:** `type()`, type conversion, debugging, string concatenation with `input()`

### 3️⃣ Mathematical Operators & BMI Calculator
Practicing the basic arithmetic operators (`+`, `-`, `*`, `/`, `**`), applying PEMDAS order of operations, and a short BMI Calculator exercise using weight and height.

**Concepts:** Arithmetic operators, order of operations (PEMDAS), exponents

### 4️⃣ BMI Calculator, Rounding & f-Strings
Continuing the BMI calculation, then rounding the result using `int()` vs. `round()`, rounding to a specific number of decimal places, and formatting output cleanly using f-strings.

**Concepts:** `int()` vs. `round()`, rounding to decimal places, f-strings

## 🎯 Key Takeaways

- Python's core data types are `str`, `int`, `float`, and `bool` — `type()` reveals which one a value is
- Values from `input()` are always strings, so they must be explicitly converted (`int()`, `float()`) before doing math with them
- `int()` truncates a decimal (rounds toward zero), while `round()` rounds to the nearest whole number — and `round(value, n)` rounds to `n` decimal places
- f-strings (`f"..."`) make it much easier to combine variables and text than manual string concatenation
