# Day 05 — For Loops & PyPassword Generator

> Part of my [100 Days of Python](https://github.com/kunal-kumar-goswami/100_days_of_python) journey — Angela Yu's Python Pro Bootcamp

Day five covers `for` loops — iterating over lists, accumulating totals, using `range()`, and combining loops with conditionals — put into practice with a randomized password generator.

## 🎯 What I Learned

- `for` loops for iterating directly over a list's items
- The accumulator pattern for manually summing or finding a maximum
- `range(start, stop, step)` for full control over a loop's sequence
- List comprehensions combined with `random.choice()`
- `random.shuffle()` and `''.join()` for building unpredictable strings

## 🛠️ Tech Stack

`Python 3` · `random` module
