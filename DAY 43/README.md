# Day 43 - Introduction to CSS 🎨

The first steps into CSS — how to attach styles to an HTML page, how to target elements with selectors, and the vocabulary for specifying colors.

## 1️⃣ Adding CSS

Practices the three ways to add CSS to a page — inline styles (`style=""` attribute), internal styles (a `<style>` block in the `<head>`), and external stylesheets (a linked `.css` file via `<link rel="stylesheet">`).

**Concepts:** Inline vs. internal vs. external CSS, the `<style>` tag, the `<link>` tag, separation of content and presentation.

---

## 2️⃣ CSS Selectors

Practices targeting HTML elements with different selector types — element selectors, class selectors (`.classname`), ID selectors (`#idname`), and combining/grouping selectors.

**Concepts:** Element, class, and ID selectors, selector specificity basics, applying styles to multiple elements at once.

---

## 3️⃣ Color Vocabulary

Explores the different ways to specify color in CSS — named colors, hex codes (`#RRGGBB`), RGB values (`rgb()`), and how these affect text, backgrounds, and borders.

**Concepts:** Named colors, hex color codes, `rgb()`/`rgba()` notation, applying color to different CSS properties.

## 🧠 Concepts Practiced (Overall)

- Attaching CSS via inline, internal, and external methods
- Element, class, and ID selectors
- Color specification (named, hex, rgb)
- The relationship between HTML structure and CSS styling
