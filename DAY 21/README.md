# Day 21 — 🧬 Inheritance

> Part of my [100 Days of Python](https://github.com/kunal-kumar-goswami/python-100-projects) journey — Angela Yu's Python Pro Bootcamp

A short exercise demonstrating class inheritance — a `Fish` class inherits from `Animal`, reuses its `breathe()` method with `super()`, and adds its own behavior.

## 🎯 Concepts Practiced

- Class inheritance (`class Fish(Animal)`)
- `super().__init__()` and `super().breathe()` to call the parent class's methods
- Overriding a method while still extending its original behavior
- Adding new methods (`swim()`) specific to the child class

## 🔑 Key Takeaways

- Inheritance lets `Fish` reuse everything `Animal` already defines (like `num_eyes` and a base `breathe()`) without rewriting it
- `super().breathe()` calls the parent's version of the method, so the child class can extend it instead of fully replacing it
- A subclass can freely add its own methods (`swim()`) that don't exist on the parent class

## 🛠️ Tech Stack

`Python 3`
