# Day 17  — The Quiz Project 🧠

> Part of my [100 Days of Python](https://github.com/kunal-kumar-goswami/python-100-projects) journey — Angela Yu's Python Pro Bootcamp

Day seventeen introduces Object-Oriented Programming (OOP) — creating classes and objects, defining attributes and methods, and organizing code into separate modules — put into practice with a True/False quiz program.

## 🗂️ Project Structure

```
DAY 17/
├── main.py              # Main program and quiz execution
├── question_model.py    # Question class
├── quiz_brain.py        # Quiz logic, questions, answers, and score
├── data.py              # Question data
└── README.md            # Project documentation
---


## 🎯 What I Learned

* Creating classes and objects using Object-Oriented Programming
* Defining attributes and methods inside a class
* Using the `__init__()` constructor to initialize object attributes
* Creating and importing custom Python modules
* Separating program logic into different files
* Using objects to represent individual quiz questions
* Managing quiz questions, answers, and score with a `QuizBrain` class
* Using loops and conditional statements to control the quiz flow

## 🛠️ Tech Stack

`Python 3`
