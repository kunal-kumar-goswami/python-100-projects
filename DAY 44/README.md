# Day 44 - Intermediate CSS 🎨📐

Building on Day 43's CSS basics — deeper into color properties, typography, and the CSS box model, then applying it all in a fun motivational meme page.

---

## 1️⃣ CSS Color

Deeper practice with color properties — `color` (text), `background-color`, and `border-color` — and how different color notations (named, hex, rgb) apply across these properties.

**Concepts:** `color`, `background-color`, `border-color`, applying color consistently across elements.

---

## 2️⃣ Font Properties

Explores CSS typography properties — `font-family`, `font-size`, `font-weight`, `font-style`, and `text-align` — to control how text looks and reads.

**Concepts:** Font stacking/fallbacks, sizing units, weight and style, text alignment.

---

## 3️⃣ CSS Box Model

Practices the core box model properties — `margin`, `border`, `padding`, and `width`/`height` — and how they interact to determine an element's total rendered size and spacing.

**Concepts:** Content box, padding, border, margin, `box-sizing`.

---

## 4️⃣ Motivation Meme

A fun combined project applying everything from this day's exercises — colors, fonts, and box model spacing — to style a motivational meme page.

**Concepts:** Composing color, typography, and layout/spacing properties into one styled page.

## 🧠 Concepts Practiced (Overall)

- CSS color properties across text, background, and borders
- Typography with font properties
- The CSS box model (margin, border, padding, content)
- Applying multiple CSS concepts together in a real styled page

## 🚀 Run It

Open any `index.html` file directly in a browser — no server needed for these static pages.
