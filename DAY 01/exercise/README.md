# Day 01 — 📝 Exercises
 
> Part of my [100 Days of Python](../../) journey — Angela Yu's Python Pro Bootcamp
 
Warm-up exercises completed before the [Day 01 project](../project) (Band Name Generator). These cover the very first Python building blocks: printing to the console, string concatenation, escape characters, variables, and the `input()`/`len()` functions.
 
## 📂 Exercises
 
### 1️⃣ Print Practice
Basic use of `print()` to output text to the console — including a multi-line "recipe steps" exercise to practice printing several statements in sequence.
 
**Concepts:** `print()` statement, strings
 
### 2️⃣ String Concatenation, New Lines & Debugging
Practice combining strings with the `+` operator, inserting line breaks inside a string using the `\n` escape character, and a short debugging drill to reinforce how `print()` and string concatenation work.
 
**Concepts:** String concatenation, `\n` escape character, debugging
 
### 3️⃣ Variables, Reassignment & `input()`
Storing values in variables, reassigning a variable to a new value, taking user input with `input()`, and using `len()` to find the length of a string.
 
**Concepts:** Variables, variable reassignment, `input()`, `len()`
 
## 🎯 Key Takeaways
 
- `print()` sends output to the console; strings can be combined with `+`
- `\n` inserts a new line inside a printed string
- Variables can be reassigned at any point in a program
- `input()` captures what the user types as a string
- `len()` returns the number of characters in a string
