# Day 01 — 🎸 Band Name Generator

> Part of my [100 Days of Python](../../) journey — Angela Yu's Python Pro Bootcamp

A simple Python program that generates a unique band name by combining the name of the city you grew up in with the name of your pet.

## 💡 What it does

The program greets the user, asks two questions — the city they grew up in and their pet's name — and combines both answers into a personalized band name.

**Example:**
```
Welcome to the Band Name Generator
Which city did you grow up in?
London
What is your pet's name?
Max
Your band name could be: London Max
```

## 🎯 Concepts Practiced

- `print()` for console output
- `input()` for capturing user responses
- Storing input in variables
- String concatenation with `+`

## 🔑 Key Takeaways

- `input()` always returns a value as a string, ready to be combined with other strings
- Multiple `input()` calls can be chained together to collect several pieces of data from the user
- String concatenation (`+`) is a simple way to merge variables and text into one output
- Breaking a program into small, clear steps (greet → collect input → combine → output) makes even a two-line result easy to follow
