# Day 09 — Dictionaries & Silent Auction

> Part of my [100 Days of Python](https://github.com/kunal-kumar-goswami/100_days_of_python) journey — Angela Yu's Python Pro Bootcamp

Day nine covers dictionaries and nested data structures — reading, adding, editing, and looping through key-value pairs, plus nested lists and dictionaries — put into practice with a silent auction program.

## 🎯 What I Learned

- Looping over a dictionary with `for key in dictionary` and accessing values with `dictionary[key]`
- Adding, editing, and removing dictionary entries
- Navigating nested lists and nested dictionaries with chained indexing/key access
- The "running maximum" pattern for finding the highest value in a collection
- Splitting logic into functions (`find_highest_bidder()`) to keep the main loop focused
