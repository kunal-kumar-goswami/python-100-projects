# Day 10 — Functions in Depth & Calculator

> Part of my [100 Days of Python](https://github.com/kunal-kumar-goswami/100_days_of_python) journey — Angela Yu's Python Pro Bootcamp

Day ten goes deeper into functions — default/keyword arguments, docstrings, function composition, and nested conditionals — put into practice with a calculator that maps operators to functions and can restart itself.

## 🎯 What I Learned

- Docstrings for documenting what a function does
- Keyword arguments for clearer, order-independent function calls
- Function composition — passing one function's output directly into another
- Mapping symbols to functions with a dictionary instead of a long `if`/`elif` chain
- `dict.get()` for safely handling missing/invalid keys
- Recursion as a way to "restart" a program's logic
