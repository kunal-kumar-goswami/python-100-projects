# Day 42 - Lists, Links & Images 🔗🖼️

Five exercises building on Day 41's HTML basics — ordered/unordered lists, deep nesting, anchor links, images, and a combined "real-world" birthday invite page.

---

## 1️⃣ List Elements

A cinnamon rolls recipe combining `<ul>` for the ingredient lists (dough + filling) and `<ol>` for the numbered step-by-step instructions.

**Concepts:** `<ul>`/`<ol>`/`<li>`, choosing ordered vs. unordered based on whether sequence matters.

---

## 2️⃣ Nesting and Indentation

A deeply nested list structure mixing `<ul>` and `<ol>` at multiple levels (e.g. `B2 → B2a → B2aa`), practicing readable indentation for nested markup.

**Concepts:** List nesting, mixing list types, consistent indentation for readability.

---

## 3️⃣ Anchor Elements

A personal top-5 favorite websites list using `<a href="">` links wrapped inside an ordered list.

**Concepts:** The `<a>` tag, the `href` attribute, combining anchors with list elements.

---

## 4️⃣ Image Elements

Two simple pages each pairing a heading with an `<img>` tag (a kitten photo and a puppy GIF), each with descriptive `alt` text.

**Concepts:** The `<img>` tag, `src` vs. `alt` attributes, accessibility via alt text.

---

## 5️⃣ Birthday Invite

A combined "real" page pulling together everything from this day's exercises: headings, an image (birthday cake), an unordered list ("what to bring"), and an anchor link to a Google Maps location.

**Concepts:** Composing headings, images, lists, and links into one cohesive page.

## 🧠 Concepts Practiced (Overall)

- Ordered and unordered lists (`<ul>`, `<ol>`, `<li>`)
- Nested list structures
- Anchor links (`<a href="">`)
- Images with accessible `alt` text (`<img src="" alt="">`)
- Composing multiple element types into a complete page

## 🚀 Run It

Open any `index.html` file directly in a browser — no server needed for these static pages.
