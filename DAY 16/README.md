# Day 16 — Object-Oriented Programming & Coffee Machine

> Part of my [100 Days of Python](https://github.com/kunal-kumar-goswami/python-100-projects) journey — Angela Yu's Python Pro Bootcamp

Day sixteen introduces Object-Oriented Programming — classes, objects, attributes, and methods — starting with the `turtle` module's built-in `Turtle` and `Screen` objects, then rebuilding the Day 15 Coffee Machine as a fully object-oriented program split across multiple classes.

## 🎯 What I Learned

- Classes as blueprints for creating objects, and objects as instances of a class
- Instance attributes (`self.name`, `self.resources`) vs. class attributes (`CURRENCY`, `COIN_VALUES`)
- Defining methods that operate on an object's own data via `self`
- Splitting a program into multiple classes/files, each responsible for one part of the system (menu, resources, payment)
- How existing library objects (like `turtle.Turtle()`) are themselves just instances of a class, with their own attributes and methods

## 🛠️ Tech Stack

`Python 3` · `turtle` module
