# Day 03 — 📝 Exercises

> Part of my [100 Days of Python](../../) journey — Angela Yu's Python Pro Bootcamp

Exercises completed before the Day 03 project. These cover conditional logic — `if`/`elif`/`else` statements, comparison operators, nested conditionals, and logical operators.

## 📂 Exercises

### 1️⃣ Movie Theater Age Check
Checks whether a user is 18 or older using a simple `if`/`else` statement, introducing comparison operators along the way.

**Concepts:** `if`/`else`, comparison operators (`>`, `<`, `>=`, `<=`, `==`, `!=`)

### 2️⃣ Even or Odd Checker
Uses the modulo operator (`%`) to determine whether a number is even or odd.

**Concepts:** Modulo operator, `if`/`else`

### 3️⃣ Movie Ticket Pricing (Nested Conditionals)
Calculates a movie ticket price based on the user's age, using nested `if` statements and a chain of `elif` conditions for different age brackets.

**Concepts:** Nested `if` statements, `elif` chains

### 4️⃣ Movie Ticket Pricing + Rating Feedback
Builds on the ticket pricing logic by adding a follow-up question asking the user to rate the movie, then responding differently based on their answer.

**Concepts:** Nested conditionals, sequential `input()` handling

### 5️⃣ Python Pizza Cafe — Order Calculator
Calculates a pizza order total based on size (quarter/half/full) and optional extras (pepperoni, extra cheese), with pricing that varies depending on the size selected.

**Concepts:** `if`/`elif`/`else` chains, cumulative totals, invalid-input handling

### 6️⃣ Logical Operators
Demonstrates how `and`, `or`, and `not` behave individually and how they combine in a more complex boolean expression.

**Concepts:** Logical operators (`and`, `or`, `not`), combined boolean expressions

## 🎯 Key Takeaways

- Comparison operators (`>`, `<`, `>=`, `<=`, `==`, `!=`) return a boolean, which is what `if` statements evaluate
- Nesting `if` statements inside each other lets a program make decisions based on multiple, dependent conditions
- An `elif` chain is cleaner than multiple nested `if`/`else` blocks when checking a value against several ranges
- Logical operators (`and`, `or`, `not`) combine multiple boolean conditions into a single decision
- Always account for invalid input (e.g. an `else` fallback) so the program doesn't fail silently on unexpected values
