# Day 18 — Turtle Graphics & Hirst Painting

> Part of my [100 Days of Python](../) journey — Angela Yu's Python Pro Bootcamp

Day eighteen goes deeper into the `turtle` module — drawing shapes, generating random colors, controlling headings, and combining loops with randomness — culminating in a generative art piece inspired by Damien Hirst's spot paintings.

### 📝 Exercises

1. [`dashed_line`](https://github.com/kunal-kumar-goswami/python-100-projects/blob/main/DAY%2018/draw_dashed_line.py) — Draws a dashed line using turtle movement and pen control.
2. [`random_move`](https://github.com/kunal-kumar-goswami/python-100-projects/blob/main/DAY%2018/draw_random_move.py) — Creates a random-walk pattern using random directions and colors.
3. [`spirography`](https://github.com/kunal-kumar-goswami/python-100-projects/blob/main/DAY%2018/draw_spirograph.py) — Generates a colorful spirograph using repeated rotations and circles.
4. [`all_shape`](https://github.com/kunal-kumar-goswami/python-100-projects/blob/main/DAY%2018/all_shape_.py) — Draws different geometric shapes using loops and turtle movement.
5. [`square`](https://github.com/kunal-kumar-goswami/python-100-projects/blob/main/DAY%2018/draw_square.py) — Draws a square using the turtle module.
6. [`turtle_graphic`](https://github.com/kunal-kumar-goswami/python-100-projects/blob/main/DAY%2018/turtle%20graphic..py) — Creates a turtle-based graphic using movement, colors, and drawing techniques.

## 🎯 What I Learned

* Creating and controlling a `Turtle` object — movement, heading, pen up/down, and speed
* Generating random RGB colors with `turtle.colormode(255)`
* Looping with `range()` to build repeating geometric patterns
* Using `tim.dot()` to place colored circles at precise grid positions
* Creating different geometric shapes with turtle graphics
* Generating random movement and directions
* Creating spirograph patterns using repeated rotations
* Debugging existing turtle code by tracing what each method call actually does

## 🛠️ Tech Stack

`Python 3` · `turtle` module
